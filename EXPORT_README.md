## Scope

Administrative government definitions, government flags and policies; administrative laws/bureaucracy and realm succession; governorship and title appointments/influence; administrative vassal contracts, powerful families and house powers; administrative factions, court and council positions, contracts, decisions, effects, triggers, script values, on-actions, event chains, historical administration titles and related UI. Includes directly related Celestial/Meritocratic/Japanese variants and referenced domicile/estate definitions. Includes all nine game localization languages present for selected content.

## Integrity

Every game file is referenced by its **original Git blob SHA**. No vanilla source content has been modified. Some shared files include non-administrative definitions because a partial rewrite would not preserve vanilla behavior.

## Important limitation

The source repository keeps JSON metadata placeholders under most `.dds`/`.png` paths instead of original binary graphics. They are NOT real game-ready textures. To obtain actual CK3 graphics, use your legitimate game installation. This archive includes the available reference paths only. Other generic vanilla game dependencies are not represented exhaustively, and this export is not a ready-to-install standalone mod.
