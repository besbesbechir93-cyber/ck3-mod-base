# Diwan - extraction du cycle dynastique chinois hors GFX

**Code réel extrait par référence aux blobs Git vanilla** depuis besbesbechir93-cyber/ck3-mod-base, commit `0ec13350cde9e410b37a46d3616966838f4ba994`.

- Version du jeu de la source: **CK3 1.20.0.3** (et non 1.20.1.1).
- 17 fichiers propres au cycle dynastique.
- 63 fichiers de localisation dans 9 langues.
- Graphismes GFX/DDS expressément exclus.
- Le répertoire `game/` préserve les chemins vanilla.
- La liste des fichiers partagés à conserver en référence est dans `MANIFESTE_DEPENDANCES.json`.

**Ne pas installer ce dossier directement comme mod complet.** Son extraction est réelle, mais le moteur CK3 requiert encore les mécanismes génériques, et les fichiers partagés doivent être intégrés de manière sélective. Aucune GUI vanilla partagée n'a été écrasée.

Télécharger ce dépôt d'extraction au format ZIP avec « Code > Download ZIP » sur cette branche, ou utiliser la route `/archive/refs/heads/diwan-cycle-hors-gfx-12003-20261017.zip`.
