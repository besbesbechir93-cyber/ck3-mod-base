# Cycle dynastique CK3 — extraction hors GFX

Source : https://github.com/besbesbechir93-cyber/ck3-mod-base, branche master, version de base **1.20.0.3**.

Cette branche exporte les fichiers dédiés au cycle dynastique chinois sans copier les infrastructures génériques du jeu. Les chemins sous game/ sont conservés. **Les fichiers partagés ne sont pas modifiés ni inclus en bloc** ; leurs points d'intégration sont répertoriés séparément.

Avertissement : extraction documentaire **non validée en jeu et non directement jouable en mod autonome**. Les ressources GFX ne figurent pas ici. Les scripts CK3 sont fournis pour étude et réintégration sélective. Le dépôt de base reste inchangé.

Voir ETAT_ET_REFERENCES.md pour les limites et les points d'intégration.
